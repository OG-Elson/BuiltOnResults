fait autorité) est le **vault de la holding** :

    vault/projects/builtonresults/

→ `handoff.md` (état vivant), plans d'acquisition, `audit_etat`, `seo_report`, `umami_runbook`, etc.

dans le vault pour rester lisibles par les agents de coordination (Cowork, Hermes) qui n'ont que le
vault monté. Historique des anciens docs : dans l'historique git de ce repo.
