# Reels — Batch 1 (scripts prêts à tourner) + backlog

> Faceless · anglais · screen recording + texte à l'écran + son trending. Voix off (VO) optionnelle.
> Cible durée : **20-35 s**. Format **9:16**. Sous-titres auto (CapCut) sur toute VO.
> ⚠️ Règle 8 : flouter/mocker tout montant perso réel — on montre le système, pas la position.

Chaque script : **Hook** (texte plein écran, 0-1,5 s, ce qui arrête le scroll) → **Beats**
(ce qu'on montre + texte/VO) → **CTA** → **audio/notes**.

---

## Reel 1 — « Track my whole budget by texting an AI » (pilier BUILD)

**Hook (texte plein écran)** : *"I track my entire budget by texting an AI ONE line."*

**Beats (screen recording) :**
1. Écran chat : je tape `suivi dépenses`. Texte : *"No app. No spreadsheet fiddling."*
2. L'IA répond en demandant les dépenses du jour. Texte : *"It asks one question."*
3. Je réponds en langage naturel (ex. *"12 groceries, 4 coffee"*). Texte : *"I answer like a human."*
4. Cut sur le dashboard : la barre Nourriture / le solde se mettent à jour. Texte : *"It writes to my Sheet + updates my live budget."*  ⚠️ montants mockés.
5. Écran final : le solde projeté. Texte : *"Budget vs real, always current."*

**CTA** : *"I'm building my one-person holding in public. Follow for the system."*
**Audio** : son trending « satisfaisant/tech ». **Durée** : ~25 s.

## Reel 2 — « My solo holding has a private cockpit » (pilier BUILD)

**Hook** : *"I run 4 ventures alone. This is the cockpit that keeps me sane."*

**Beats (screen recording — scroll du dashboard) :**
1. Vue « Coup d'œil » : chiffre héros + jauge North Star. Texte : *"One screen. Am I on track?"*  ⚠️ mocker les €.
2. Scroll trajectoire (courbe vers 2000). Texte : *"Trajectory to my goal, live."*
3. Vue Budget (prévu vs réel, barres). Texte : *"Planned vs real, per envelope."*
4. Runway / alertes. Texte : *"It flags what's off before I do."*
5. Écran final. Texte : *"Built with a Google Sheet + AI. No SaaS, no subscription."*

**CTA** : *"Follow — I show how I build these systems."*
**Audio** : son posé « focus ». **Durée** : ~30 s.
**Note** : c'est le reel « waouh visuel » — le dashboard raconte tout seul.

## Reel 3 — « My safety check said 'all clean.' It lied. » (pilier JOURNEY — leçon)

**Hook** : *"My automated safety check said everything was clean. It was lying — and that's worse than no check."*

**Beats :**
1. Écran : le contrôle affiche `OK — rien à signaler`. Texte : *"Green. Reassuring, right?"*
2. Cut : les vraies fuites qu'il avait ratées (vocabulaire/périmètre trop étroits). Texte :
   *"It missed real leaks — it only looked in the wrong places, for the wrong words."*
3. Le correctif (périmètre élargi + re-test). Texte : *"Fix: test the check on a case that MUST fail."*
4. Écran final. Texte : *"A check that wrongly says 'clean' kills your vigilance. Untested rule = no rule."*

**CTA** : *"Lessons from building solo, in public. Follow."*
**Audio** : son « tension → résolution ». **Durée** : ~30 s.
**Pourquoi ça marche** : vulnérabilité + insight généralisable = format fort en build-in-public.
